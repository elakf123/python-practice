# Python Practice

Мои учебные проекты на Python и bash.

## Проекты

- **calculator.py** — калькулятор на функциях и словаре,
  с тестами (pytest).
- **log_stats.py** — подсчёт уровней в лог-файле
  (INFO / WARNING / ERROR), с тестами.
- **todo_json.py, todo_sql.py** — менеджер задач
  с хранением в JSON и в SQLite.

## Запуск тестов

    python3 -m pytest

## Остальное

- `exercises/` — учебные упражнения (циклы, списки,
  словари, функции, файлы, ошибки).
- `scripts/` — bash-скрипты.
